This is my assignment for the Advanced CSS project for Wincacademy. It asked to use images and/or challenge kit from frontendmentor.io or dribble to build a responsive landingpage. 

Test of live site is published via netlifly:
https://skilhuz-css-advanced-landingpage.netlify.app/

Favorite things I learned: 

Using clamp and calc to get better responsive layout type scales
Use of css transitions and filter (blending modes in code like what I do in Photoshop - very cool) to get smooth hover transitions (Tips from CSStricks, Kevin Powell tutorials, + Wincacademy)
Z-index for layering elements (how to get the phones to appear floating outside container)
Grid

Things I struggled with:

Remembering to code mobile-first. Had to reshuffle code after first round because I realized I was still thinking desktop first.
Getting hero image and background to behave responsively (after online help use of minmax with calcs made the closest solution but still not quite there yet..)
Grid (No, this was not a mistake. I love it more than flex but it does get very overwhelming. Did extra practice with CSS Grid garden.)
